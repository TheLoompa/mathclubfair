Put your club logo in this folder, named  logo.png

- Square image works best (it gets cropped into a circle).
- 400x400 px or larger.
- PNG with a transparent background looks best, but any image works.
- If you use a different filename or an .svg, update `logo:` in js/config.js.

If there's no logo here, the presentation shows a pink circle with a
big π in it instead — which looks fine, so this is optional.
